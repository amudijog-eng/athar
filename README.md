# 🌿 منصة «أَثَـر» | صدقة جارية إلكترونية متكاملة
> **«أثرٌ يبقى .. وأجرٌ يرقى»**  
> قال رسول الله ﷺ: **«إِذَا مَاتَ الإِنْسَانُ انْقَطَعَ عَنْهُ عَمَلُهُ إِلاَّ مِنْ ثَلاَثَةٍ: إِلاَّ مِنْ صَدَقَةٍ جَارِيَةٍ، أَوْ عِلْمٍ يُنْتَفَعُ بِهِ، أَوْ وَلَدٍ صَالِحٍ يَدْعُو لَهُ»** *(صحيح مسلم)*.

---

## 📖 نبذة عن المشروع
تم تصميم وتطوير موقع **«أثر»** ليكون منصة إسلامية شاملة، عصرية، ومتقنة بأعلى معايير التصميم وتجربة المستخدم (UI/UX)، تم بناؤها بنية خالصة لتكون **صدقة جارية** لوجه الله تعالى عن صاحب الموقع ووالديه وأهله وكل من ساهم في نشرها أو انتفع بها.

الموقع **مجاني بالكامل**، **خالٍ تماماً من أي إعلانات تجارية أو نوافذ منبثقة**، ويعمل بكفاءة فائقة على جميع الأجهزة (الهواتف، الأجهزة اللوحية، والحواسيب) مع إمكانية التثبيت كتطبيق هاتف (PWA) ودعم العمل دون إنترنت (Offline).

## 🌟 الأنظمة والميزات المكتملة في المنصة

### 🕋 1. القرآن الكريم كاملاً (المصحف الشريف)
- فهرس كامل لـ **114 سورة** مع بيانات السورة (مكية/مدنية، عدد الآيات، رقم الجزء، ورقم الصفحة).
- تصفح بالسور أو الأجزاء (30 جزءاً) مع بحث فوري ذكي.
- عرض النص القرآني بالرسم العثماني المعتمد مع تشكيل دقيق وعلامات الآيات `﴿١﴾`.
- **التفسير الميسر** لكل آية بنقرة واحدة.
- **مشغل تلاوات صوتية** لكبار القرّاء (مشاري راشد العفاسي، عبد الباسط عبد الصمد، ماهر المعيقلي، محمود خليل الحصري، محمد صديق المنشاوي، سعد الغامدي).
- تحديد وحفظ **آخر موضع وصلت إليه** تلقائياً في المتصفح لمتابعة القراءة لاحقاً.
- ميزة تكبير وتصغير حجم الخط (A- / A+) مع وضع حماية العين (سيبيا) والوضع الليلي.
- إمكانية نسخ الآية، مشاركتها كبطاقة مصممة، وإضافتها للمفضلة.

### 📿 2. الأذكار اليومية وحصن المسلم
- 11 تصنيفاً للأذكار: (أذكار الصباح، أذكار المساء، أذكار النوم، الاستيقاظ، بعد الصلاة، السفر، الطعام والشراب، المنزل، المرض والشفاء، المطر والريح، وتفريج الكرب والهم).
- عداد تفاعلي لكل ذكر (1، 3، 33، 100) مع اهتزاز لمسي (Haptic) وصوت نقر خافت.
- بيان فضل كل ذكر ومصدره من أصح كتب السنة (صحيح البخاري، مسلم، الترمذي، أبو داود).
- علامة إنجاز خضراء "تم بحمد الله" مع شريط تقدم يوضح نسبة إنجاز أذكار القسم.

### 📿 3. المسبحة الإلكترونية المتطورة
- عداد تفاعلي كبير ثلاثي الأبعاد مع حلقة تقدم دائرية ومؤثرات حركية أنيقة.
- أذكار جاهزة (سبحان الله، الحمد لله، الله أكبر، لا إله إلا الله، الصلاة على النبي ﷺ، أستغفر الله).
- **إمكانية كتابة ذكر مخصص** وتحديد الهدف التكراري.
- خيارات أهداف: (33، 100، 1000، أو تسبيح مفتوح).
- تتبع الدورات (Laps) وإجمالي التسبيحات الدائم المحفوظ في الذاكرة المحلية.

### 🤲 4. محراب الاستغفار
- صفحة مخصصة للزم الاستغفار: «أَسْتَغْفِرُ اللَّهَ الْعَظِيمَ وَأَتُوبُ إِلَيْهِ».
- تحديد أهداف يومية: (100، 500، 1,000، 10,000 استغفار).
- بطاقة خاصة بـ **سيد الاستغفار** مع نصه الكامل وشرح فضله ومصدره.
- بيان فضائل وثمار الاستغفار في تفريج الهموم وسعة الأرزاق.

### 📚 5. قسم الأحاديث النبوية الصحيحة
- أحاديث صحيحة موثقة ومحققة (صحيح البخاري، صحيح مسلم، رياض الصالحين).
- مصنفة موضوعياً: (الصدقة الجارية، بر الوالدين وحسن الخلق، الصبر وتفريج الكرب، فضل القرآن، التوبة والاستغفار).
- توثيق الراوي، المصدر، والدرجة (صحيح / متفق عليه).
- شرح ميسر لكل حديث لتقريب معناه وفهمه.
- حديث اليوم النبوي المتجدد.

### 🤲 6. الأدعية القرآنية والنبوية الشاملة
- أدعية القرآن الكريم، أدعية الأنبياء عليهم السلام، أدعية تفريج الكرب، الرزق، الشفاء، والسفر.
- أدعية خاصة لـ **بر الوالدين**، وأدعية لـ **المتوفين ومن سبقونا**.
- زر **«قرأتُ هذا الدعاء»** لتشجيع الاستمرار.

### 🕌 7. مواقيت الصلاة وبوصلة القبلة
- حساب فلكي دقيق لمواقيت الصلوات الخمس والشروق (وفق معيار رابطة العالم الإسلامي).
- تحديد تلقائي للموقع الجغرافي (GPS) أو اختيار مدينتك من قائمة كبرى العواصم.
- **عداد تنازلي دقيق** للصلاة القادمة (ساعات ودقائق).
- عرض التقويم الهجري والميلادي.
- **بوصلة القبلة التفاعلية**: توضح زاوية اتجاه الكعبة المشرفة بالنسبة للشمال الجغرافي، مع حساب المسافة بالكيلومتر إلى مكة المكرمة.

### 📋 8. وردي اليومي
- قائمة مهام يومية لطاعات المسلم (سورة الكهف، 100 استغفار، 100 صلاة على النبي ﷺ، أذكار الصباح والمساء، ورد القرآن).
- حساب نسبة الإنجاز اليومية المئوية، مع تذكير خاص بسنن يوم الجمعة.
- احتفال بتأثيرات بصرية راقية (Confetti) عند اكتمال الورد.

### 📖 9. خطة ختمة القرآن ومُعين الحفظ
- حساب خطة الختمة: (ختمة في 7 أيام، 15 يوماً، 30 يوماً، أو 60 يوماً).
- حساب تلقائي لعدد الصفحات المطلوبة يومياً ودبر كل صلاة مكتوبة.
- أداة **مُعين الحفظ**: تكرار الآية، إخفاء/تعتيم الآية للاختبار الذاتي، وإظهارها عند الحاجة.

### 🕊️ 10. الصدقة الجارية، لمن سبقونا، وبر الوالدين
- صفحة الوقف وبيان النية الصادقة للموقع.
- صفحة للدعاء لجميع موتى المسلمين: «اللهم اغفر للمؤمنين والمؤمنات الأحياء منهم والأموات».
- قسم خاص ببر الوالدين في الحياة وبعد الممات.
- **دليل استمرارية الوقف للأبد**: خطوات عملية واضحة لصاحب الموقع لضمان بقائه أونلاين حتى بعد وفاته.

### 🎧 11. مشغل القرآن الصوتي العائم
- شريط تشغيل عائم أسفل الشاشة يستمر بالعزف والتلاوة أثناء التنقل بين كافة صفحات وأقسام المنصة دون انقطاع.
- تقديم وتأخير 10 ثوانٍ، تكرار السورة، تحكم بالسرعة (0.75x, 1x, 1.25x, 1.5x)، والتبديل المباشر بين القرّاء.

### 🔍 12. البحث الشامل الذكي (Ctrl+K)
- نافذة بحث سريعة تبحث بالتزامن في: سور القرآن، نصوص الأحاديث، الأذكار، والأدعية مع توجيه فوري للمحتوى.

### 🎨 13. مولد بطاقات المشاركة ("انشر الأجر")
- تحويل أي آية أو حديث أو ذكر إلى **بطاقة جرافيك إسلامية عالية الدقة** جاهزة للتحميل كصورة PNG ومشاركتها على واتساب وإنستغرام وإكس (تويتر).
- 4 تصاميم لونية إسلامية: (الزمردي الليلي، الذهبي الملكي، الليلي الهادئ، والرملي الفاتح).

### 🌍 14. التعدد اللغوي (Multilingual)
- العربية (اللغة الأساسية)، English، اردو، Türkçe، Français، Bahasa Indonesia.

## 🔍 الأرشفة ومحركات بحث جوجل (Google SEO)
تم تجهيز الموقع ليحصل على أعلى تقييم أرشفة وسرعة في محركات البحث (100/100 Lighthouse SEO):
1. **Semantic HTML5 Tags**: استخدام وسوم `header`, `nav`, `main`, `article`, `section`, `footer`.
2. **Meta Tags كاملة**: العناوين، الوصف الموجه، الكلمات المفتاحية، والوسوم الكنسية (Canonical URL).
3. **OpenGraph & Twitter Cards**: لظهور روابط الموقع بشكل بطاقة احترافية جذابة عند مشاركتها على وسائل التواصل.
4. **JSON-LD Schema Markup**: وسوم البيانات المنظمة المعتمدة لدى جوجل لمواقع المحتوى الإسلامي والقرآني والبحث الداخلي.
5. **Sitemap.xml & Robots.txt**: ملفات فهرسة قياسية ترشد عناكب محركات البحث وتسهل فهرستها في Google Search Console.
6. **PWA & Offline Ready**: ملف `manifest.json` و `sw.js` يتيحان سرعة تحميل فائقة وتثبيت الموقع على الهواتف.

## 🕊️ دليل استمرارية الصدقة الجارية (ماذا بعد الوفاة؟)
لضمان استمرار الموقع صدقة جارية لك ولأهلك لعشرات السنين دون أن يتوقف:

1. **الاستضافة المجانية الدائمة (Zero Hosting Costs)**:
   - الكود مبني بالكامل كـ Static Single Page Application (SPA).
   - قم برفع المشروع على **GitHub Pages** أو **Cloudflare Pages** أو **Vercel**. هذه المنصات مجانية للأبد، ولا تطلب بطاقة دفع ولا تلغي الموقع عند انتهاء أي اشتراك.
2. **حجز الدومين لأطول فترة**:
   - احجز الدومين الخاص بك (مثلاً: `athar-app.org` أو `athar.net`) لمدة 5 أو 10 سنوات مقدماً وفعّل التجديد التلقائي (Auto-Renew).
   - حتى لو لم ترغب بدومين مدفوع، رابط GitHub Pages المجاني (مثل `username.github.io/athar`) يظل يعمل مدى الحياة مجاناً.
3. **تعيين أمناء للمستودع (Trusted Trustees)**:
   - قم بإضافة شخص أو أكثر من أهل الثقة (أخوك، ابنك، أو صديق صالح) كمسؤول (Collaborator / Admin) على حساب GitHub وحساب الدومين.
4. **الوصية الشرعية**:
   - دوّن في وصيتك أن هذا الموقع وقف إسلامي غير ربحي لوجه الله تعالى، واذكر بيانات الدومين لضمان متابعته وتجديده.

## 💻 طريقة تشغيل وبناء المشروع محلياً

```bash
# 1. الدخول لمجلد المشروع
cd athar-platform

# 2. تشغيل الموقع محلياً للمعاينة والتطوير
npm run dev

# 3. بناء نسخة الإنتاج النهائية الجاهزة للرفع
npm run build

# 4. معاينة نسخة الإنتاج
npm run preview
```

ينتج مجلد `dist`، وهو مجلد مستقل تماماً يحتوي على ملفات الموقع الجاهزة للنشر المباشر على أي استضافة (cPanel، GitHub Pages، Netlify، Vercel، أو Cloudflare).
